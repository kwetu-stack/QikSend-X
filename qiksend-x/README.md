# QikSend-X™ 🚚📦

A modern courier and delivery management system built with Flask and SQLite.

---

## 🔧 Features

- 📦 Book new deliveries
- 🚴 Assign riders/drivers
- 📍 Track parcel status
- 🧑‍🤝‍🧑 Manage sender/receiver details
- 💰 Mark payments (Paid / Unpaid)
- 📊 Live dashboard
- 🔐 Login/logout system
- ❌ 404 fallback page

---

## 🖥️ Tech Stack

- Python 3
- Flask (Backend Framework)
- SQLite (Database)
- HTML/CSS (Frontend)
- Jinja2 Templates

---
